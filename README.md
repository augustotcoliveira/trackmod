# TrackMod 🏎️

Aplicativo para gerenciamento de garagem e controle de peças de veículos de alta performance. Desenvolvido como projeto final da disciplina **SI700 (Programação para Dispositivos Móveis)** na **Faculdade de Tecnologia - UNICAMP**.

---

## 🚀 Funcionalidades

* **Vitrine Pública:** Projetos da comunidade e destaques automotivos.
* **Minha Garagem:** Cadastro de peças (com fotos da câmera/galeria), filtros por categoria, edição, exclusão, cálculo de investimento total e gráfico em tempo real.
* **Autenticação:** Login e cadastro individualizados via Firebase Authentication.
* **Banco de Dados em Nuvem:** Persistência e sincronização de dados via Cloud Firestore.
* **Perfil do Piloto:** Painel com estatísticas da garagem, dados da conta e menu de opções.

---

## 🛠️ Tecnologias

* **Flutter & Dart** (SDK ^3.5.0)
* **BLoC (`flutter_bloc`)** — Gerenciamento de estado (3 camadas: View, BLoC, Data Provider)
* **Firebase Authentication** — Autenticação de usuários
* **Cloud Firestore** — Banco de dados em tempo real
* **Image Picker** — Captura e upload de imagens
* **Intl & Google Fonts** — Formatação de moedas/datas e estilo visual
